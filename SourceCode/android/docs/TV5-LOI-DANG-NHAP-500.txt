KẾT LUẬN
Android đã tới bước gọi API đổi Firebase ID Token. Backend hiện tại chưa có endpoint
để tạo/tìm user và phát JWT CityGuard. Không sửa SHA hoặc đổi tài khoản Google để xử lý lỗi này.
GlobalExceptionHandler hiện catch Exception và trả 500, có thể che cả lỗi không tìm thấy route;
TV5 cần phân loại lỗi route 404 riêng khi hoàn thiện xử lý lỗi server.
Không phát JWT giả hoặc cho Android vào main khi server chưa chấp nhận token.

TV5 CẦN LÀM
1. Triển khai POST /api/v1/auth/firebase nhận idToken và provider GOOGLE/FACEBOOK.
2. Firebase Admin verify token với project cityguardapp-1f6c5.
3. Migration và mapping UID -> users.id; tạo user mới hoặc dùng user cũ.
4. Giữ contract AuthResponse hiện có, expiresIn theo millisecond.
5. Xử lý social user không có email/password local; không gộp email tùy tiện.
6. Chạy lại API và báo cho TV2 endpoint/base URL để kiểm thử thật.
